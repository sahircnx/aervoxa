# Aervoxa — Authored da.live Pages

> Block names below match the **actual Aervoxa project blocks** (`hero`, `features-grid`,
> `product-showcase`, `cards`, `columns`, `text`, `title`) — not generic EDS defaults.
> Copy each table into the matching da.live document. Sections are separated by `---`.
>
> Block content-model notes (from repo):
> - **hero**: image, then eyebrow `<p>`, `<h1>`, subcopy, **primary CTA** (bold link), *secondary CTA* (italic link), and a trust `<ul>`.
> - **features-grid**: one row per feature = icon image · heading+description · optional link.
> - **product-showcase**: one row per product = image-only column · content column (h3, bullet `<ul>`, bold "Learn More" link). Rows auto-alternate left/right.
> - **cards**: one row per card = image · body.
> - **columns**: N columns per row; supports `grid` / `ratio-x-y` variants.
> - **section-metadata** `Style` values seen in project: `highlight`.
